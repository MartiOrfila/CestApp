---
name: Llista compartida product scope
description: Product language and sharing scope for the shopping-list app.
---

The app is Catalan-first. The user wants shopping lists that can be shared through WhatsApp, Gmail, Instagram, and similar channels. Live cross-device collaboration was not requested.

**Why:** This records what “shared” means for the product so future work does not add accounts or synchronization by assumption.

**How to apply:** Preserve Catalan UI and straightforward list sharing unless the user explicitly requests collaborative sync.

---
name: Llista compartida product scope
description: Product language and sharing scope for the shopping-list app.
---

The app is Catalan-first. The user wants shopping lists that can be shared through WhatsApp, Gmail, Instagram, and similar channels, as well as edited live by other app users with access.

**Why:** The user clarified that participants should edit the same synchronized list, not just receive separate copies.

**How to apply:** Preserve Catalan UI and support both external text sharing and authenticated, synchronized participant access.
